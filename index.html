01

Prime

Calcium accelerates two reversible priming steps from empty sites through loosely primed to tightly primed vesicles.

02

Release

Each action potential releases a fraction of TS and optional TSL pools according to a dynamic release probability.

03

Recover

Released sites return directly or pass through a refractory state, while calcium and modulation variables relax between pulses.

Research-use notice: This is a simulation and educational tool—not medical software. Confirm quantitative results against the reference Python implementation before publication.
